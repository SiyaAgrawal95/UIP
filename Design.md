# Design.md
## Project: Urine Test Strip Reader using Colorimetry as a Point-of-Care Technology

---

# Website Goal

Design a modern, professional, healthcare-focused landing page for an AI-powered Urine Test Strip Reader that uses Colorimetry as a Point-of-Care (PoC) diagnostic technology.

The website should create trust among hospitals, laboratories, clinics, and healthcare professionals while showcasing the device's AI-powered urine analysis capabilities.

The interface should feel premium, clean, minimal, and medical.

# Overall Visual Theme

The website should resemble a premium healthcare technology company similar to Siemens Healthineers, Abbott, Roche Diagnostics, or Healthy.io, while focusing on a dedicated AI-powered urine test strip reader device instead of a smartphone application. The interface should inspire confidence, professionalism, innovation, and medical reliability.
